# Local Vid Viewer


## Features

* **No Setup:** Runs locally in one/two clicks (Or use my github pages link)
* **Batch File Selection:** Select and load multiple video files (from your PC.)
* **Interactive Playlist:** Clean dark-mode sidebar that lists all loaded videos
* **Full Media Controls:** Standard video playback
* **Cross-Browser Compatible:** Works on Firefox, Chrome, Edge, and Safari. (Unless for some reason you don't have an HTML5 browser, and in that case screw you)

## Getting Started

1. Download or copy the `index.html` file into a folder on your computer, Or go to the Github Pages link.
2. Double-click **`index.html`** to open it in your web browser. (Unless using the Github Pages link)
3. Click the **Choose Videos from PC** button in the sidebar.
4. Select your video files (supports `.mp4`, `.mkv`, `.webm`, `.mov`, `.avi`, and more).
5. Click a video in the playlist (that you imported) to start playing!
